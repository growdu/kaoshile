## 0. 使用说明

- 本清单**不是最终数据**，每条考试在灌入数据库前必须由**管理员**对照官方源复核一次（参见 `data_sources.md §4.4`）；
- 文档中的「典型时间」是历史规律描述，**不替代**官方公告；
- 管理员录入时请按本文档提供的「权威源 URL 栏目」定位公告；
- 商业认证类已标注「不收录」原因，请勿误录。

## 10. 明确**不收录**的考试（再次强调）

下列认证 / 考试**不属于「公开考试」**，请勿录入：

- **PMP / PMI 认证**（商业、PMI 会员制）
- **阿里云 / 华为云 / 腾讯云 / AWS / Azure / Oracle** 等云厂商认证
- **CISCO / Red Hat / Huawei HCIE / H3C** 等网络认证
- **ACCA / CFA / FRM** 等国际财经认证
- **雅思 / 托福 / GRE / GMAT** 等境外考点主导的考试（仅按考点标注，不抓时间表）
- **企业内部 OJT 考试、培训结业**

## 11. 灌入格式（管理员录入脚本 / seed_demo.py 模板）

```yaml
# 灌入一条考试记录的 Yaml 样例
- name: "信息系统项目管理师（2026 下半年）"
  category: "IT"
  organizer: "工信部 / 人社部"
  registration_start: "2026-08-15T00:00:00+08:00"
  registration_end:   "2026-09-05T23:59:59+08:00"
  payment_end:        "2026-09-10T23:59:59+08:00"
  admission_ticket_start: "2026-10-25T00:00:00+08:00"
  exam_date:          "2026-11-07T09:00:00+08:00"
  official_url: "https://www.cpta.com.cn/..."
  source_url: "https://www.cpta.com.cn/..."
  source_hash: "<sha256 of 公告正文>"
  status: open
  # 由管理员首次复核时填入
  # last_verified_at: 2026-09-01T10:00:00+08:00
  # verifier: admin
```

> 管理员在 `scripts/seed_demo.py` 中读取 yaml 文件后逐条入库；每条入库后**立即通过管理员后台点击「确认无误」**填写 `last_verified_at`。

## 12. 灌入清单维护规则

- 管理员每季度对清单做一次「复核 + 增删」；
- 删除：考试已完成且无后续场次（如软考上半年已考完、且无下半年）的，可保留作历史归档（`status=archived`）以供查询；
- 新增：清单外的新考试由管理员在管理后台手动新建，不必修改本文档；但若涉及**新增数据源**，必须同步更新 `data_sources.md §3` 白名单；
- 任何对清单的更新需在 commit message 中明确「seed_exams.md 增 / 删 X 条」。
